# Professional Student Project Assistance Platform

> **College Projects Made Simple.**
> Affordable academic project assistance, presentation PPTs, reviews, documentation, and technical mentoring designed specifically for college & university students.

---

## 🌟 Key Features

### 🎓 1. Progressive College Student Questionnaire
- **Smart Category Routing**: Customized forms for College Projects, PPTs, Reviews, Data Science, AI/ML, and Technical Assistance.
- **Academic Profile Sync**: Automatically synchronizes year of study (1st, 2nd, 3rd, Final Year) with corresponding college semesters.
- **1st-Year Simplified Flow**: Clean non-technical workflow for first-year engineering students without complex jargon.

### 💰 2. Ultra-Affordable Pricing Matrix (Strictly ₹100 – ₹700 Maximum)
- **Hard Price Ceiling**: All platform calculations are capped at **₹700 maximum**.
- **Low-Cost Dedicated PPT Rates**:
  - 5–7 Slides: **₹100**
  - 8–10 Slides: **₹150**
  - 11–15 Slides: **₹200**
- **Transparent Project Tiers**:
  - Basic 1st-Year Project: **₹200 – ₹450**
  - College Mini Project: **₹300 – ₹550**
  - Major Capstone Project: **₹400 – ₹700 Max**
- **Dynamic Deadline Savings**: Submitting 7+ days in advance unlocks the lowest baseline price with ₹0 urgency charges.

### 📁 3. User-Controlled File Upload System
- Starts clean with 0 pre-filled dummy files.
- Drag & drop dropzone with multi-format support: PDF, DOCX, PPTX, ZIP, RAR, Python (.py), Java, CSV, Excel, and images.
- Instant file preview, size calculation, and quick remove controls.

### 📱 4. Custom UPI QR Code & Manual Verification
- **Prominent UPI QR Display**: Scannable with Google Pay, PhonePe, Paytm, and BHIM.
- **One-Click UPI ID Copy**: Quick copy button for `apexproject@upi`.
- **Manual Verification**: Students enter their 12-digit UTR number and attach optional payment proof screenshot.
- **Super Admin Approval Queue**: Dedicated Admin tab to inspect screenshots, approve payments, or reject with explanatory feedback.

### 📦 5. Deliverables Vault & Download System
- Deliverables remain securely gated until code is compiled and payment is verified.
- Clear empty state: *"Your final files will appear here once they are ready."*
- Full download package: Source code ZIP, formatted PPTX deck, IEEE report PDF, and Viva cheat-sheet.

### 🛠️ 6. Super Admin Operations Hub
- **Payment Verification Queue**: Approve or reject manual UPI transactions.
- **Payment QR Settings**: Upload custom UPI QR code and set official UPI ID with live checkout preview.
- **Dynamic Pricing Controls**: Real-time matrix adjustment for base rates, slide counts, and urgency adders.
- **Mentor Roster & Assignment**: Assign verified academic mentors to incoming orders.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/amitkush7373-prog/Professional-Student-Project-Assistance-Platform.git
cd Professional-Student-Project-Assistance-Platform
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```
Open `http://localhost:3000/` (or `http://localhost:3001/`) in your browser.

### 4. Build for production
```bash
npm run build
```
